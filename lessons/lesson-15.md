# 整合小專題 🛠️

## 班級成績管理小程式

1. 讀入 n 個學生（**結構陣列**）
2. 算全班平均（**函式 + 陣列**）
3. 找最高 / 最低分（**找極值**）
4. 依分數排序印排名（**結構排序**）
5. 統計及格人數（**分支 + 計數**）

> 拆成 5 個小函式，一個一個完成
