# 算術運算子

| 運算子 | 意思 | `7 ? 2` |
|--------|------|---------|
| `+ - *` | 加減乘 | — |
| `/` | 除（取商） | **`3`** |
| `%` | 取餘數 | `1` |

> 🍬 7 顆糖分給 2 人：
> 每人 `7 / 2 = 3` 顆，剩 `7 % 2 = 1` 顆

---

# ⚠️ 整數除法陷阱

```c
int a = 7, b = 2;
printf("%d\n", a / b);      // 3，不是 3.5！
```

兩個整數相除 → 結果還是整數（小數被丟掉）

解法：讓其中一個是小數
```c
printf("%.1f\n", 7.0 / 2);  // 3.5 ✅
```

---

# 關係運算子（結果：真=1 / 假=0）

```c
5 > 3    // 1（真）
5 == 3   // 0（假）
```

# ⚠️ 相等是 `==` 不是 `=`

- `==` 比較「相不相等」
- `=`  是「指派」（把右邊放進左邊）

> `if (x = 5)` 不會報錯，但邏輯整個錯！

---

# 邏輯運算子

| 運算子 | 意思 | 例子 |
|--------|------|------|
| `&&` | 而且 | `age>=18 && age<=65` |
| `\|\|` | 或者 | `s<0 \|\| s>100` |
| `!` | 否定 | `!(x==0)` |

`&&`：兩個都真才真
`||`：一個真就真

---

# 優先序：記不住就加括號

順序（大概）：
`!` ＞ `* / %` ＞ `+ -` ＞ `> <` ＞ `&&` ＞ `||`

```c
2 + 3 * 4      // 14（先乘後加）
(2 + 3) * 4    // 20
```

> 💡 口訣：**不確定就加括號**，清楚最重要

---

# 型別轉換

要算小數結果，用 `(float)` 強制轉型：

```c
int a = 5, b = 2;
float ans = (float)a / b;   // 2.5
printf("%.1f\n", ans);
```

> 沒轉型的話 `a / b` 會先算成整數 2，再變 2.0
